# 사진 넣는 폴더

이 폴더에 숙소 사진을 올린 뒤, `js/config.js` 에서 `image: ""` 부분에 파일 이름을 적어 주세요.

예) `image: "images/room1.jpg"`

추천 파일 이름: hero.jpg(첫 화면), about.jpg(소개), room1.jpg~room3.jpg(객실), spring.jpg·summer.jpg·autumn.jpg·winter.jpg(계절), map.png(지도 캡처)

- 직접 찍었거나 사용 허락을 받은 사진만 올려 주세요.
- 가로 1600px 정도, 용량 500KB 이하로 줄여서 올리면 휴대폰에서 빨리 열립니다.
- 파일 이름은 영어 소문자·숫자로 짓는 것이 안전합니다. (한글·띄어쓰기 X)
