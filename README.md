# 🌲 솔바람 시골집 — 시골집 손님방 홈페이지

시골 손님방(민박)을 소개하는 **무료 홈페이지**입니다.
휴대폰에서 보기 좋게 만들어졌고, 별도 프로그램 설치 없이 GitHub Pages로 바로 공개할 수 있습니다.

> ⚠️ 지금 들어 있는 숙소 이름·주소·전화번호·대표자·사업자번호는 모두 **가상의 예시**입니다.
> 공개하기 전에 꼭 실제 내용으로 바꿔 주세요.

## 들어 있는 내용

첫 화면 · 숙소 소개 · 객실 안내(요금 계산기 포함) · 시설·즐길거리 · 사계절 사진 · 주변 관광지 ·
이용 안내(체크인/아웃, 환불 규정, 주의사항) · 오시는 길 · 자주 묻는 질문 · 예약 문의(전화/카카오톡/네이버 예약)

휴대폰에서는 오른쪽 위 ☰ 메뉴와 화면 아래 **"예약 문의하기"** 고정 버튼이 나타납니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `js/config.js` | ⭐ **내용 수정은 이 파일 하나만!** (이름, 가격, 객실, 연락처, 주소, FAQ 등) |
| `images/` | 사진을 넣는 폴더 |
| `index.html` | 페이지 뼈대 (보통 고칠 필요 없음) |
| `css/style.css` | 색상·디자인 (맨 위 `:root` 부분에서 색 변경 가능) |
| `js/main.js` | 메뉴·계산기 등 동작 (고칠 필요 없음) |

## ✏️ 내용 고치는 방법 (GitHub 웹사이트에서 바로)

1. 저장소에서 `js` 폴더 → `config.js` 를 누릅니다.
2. 오른쪽 위 **연필(✏️) 아이콘**을 누릅니다.
3. **따옴표 `" "` 안의 글자만** 바꿉니다. 따옴표, 쉼표(`,`), 괄호는 지우지 마세요.
   - 가격은 숫자만: `priceWeekday: 90000,`
   - 카카오톡/네이버 예약 주소는 `"#"` 자리에 `"https://..."` 주소를 붙여 넣습니다.
4. 아래 초록색 **Commit changes** 버튼을 누르면 저장됩니다. 1~2분 뒤 홈페이지에 반영돼요.

객실을 추가하려면 `rooms` 안의 `{ ... },` 묶음 하나를 통째로 복사해 붙여 넣고 내용을 바꾸면 됩니다.
(FAQ, 시설, 관광지도 같은 방법)

> 수정 후 화면이 하얗게 나오면 따옴표나 쉼표가 빠진 경우가 대부분입니다. 바로 전에 고친 줄을 확인해 주세요.

## 🖼️ 사진 바꾸는 방법

지금은 사진 대신 **"사진 교체 위치"** 라고 적힌 무늬 상자가 보입니다.

1. 저장소의 `images` 폴더로 들어가 **Add file → Upload files** 로 사진을 올립니다.
   - 파일 이름은 영어 소문자로: `room1.jpg`, `hero.jpg` 등 (한글·띄어쓰기 X)
   - 가로 1600px 정도, 500KB 이하로 줄이면 휴대폰에서 빨리 열립니다.
2. `js/config.js` 에서 해당 자리의 `image: ""` 를 `image: "images/room1.jpg"` 처럼 바꿉니다.

| 자리 | config.js 항목 |
|---|---|
| 첫 화면 큰 사진 | `heroImage` (비워 두면 시골집 그림이 나옵니다) |
| 숙소 소개 사진 | `about.image` |
| 객실 사진 | 각 객실의 `image` |
| 사계절 사진 | `gallery` 의 각 `image` |
| 지도 | `location.mapImage` (네이버/카카오 지도 화면 캡처) + `location.mapLinkUrl` (지도 링크) |

※ 직접 찍었거나 사용 허락을 받은 사진만 사용해 주세요. 인터넷에서 찾은 사진은 저작권 문제가 생길 수 있어요.

## 🚀 무료로 인터넷에 공개하기 (GitHub Pages)

1. 저장소 위쪽 **Settings**(설정) 탭을 누릅니다.
2. 왼쪽 메뉴에서 **Pages** 를 누릅니다.
3. **Build and deployment → Source** 를 **Deploy from a branch** 로 둡니다.
4. **Branch** 를 `main`, 폴더를 `/ (root)` 로 고르고 **Save** 를 누릅니다.
5. 1~3분 뒤 아래 주소로 접속하면 홈페이지가 보입니다.

👉 **https://wkh8503-cmyk.github.io/country-guesthouse/**

이 주소를 네이버 플레이스, 인스타그램 프로필, 카카오톡 채널 등에 붙여 두면 됩니다.

## 🎨 색 바꾸기 (선택)

`css/style.css` 맨 위 `:root { ... }` 안의 색상 코드를 바꾸면 전체 색이 바뀝니다.
예) `--c-accent: #9c4a26;` → 버튼 색
