# 시골집손님방 홈페이지

실제 객실 101호 A·102호 B·103호 C와 숙소 사진 82장을 사용하는 정적 홈페이지입니다.
공개 주소: https://wkh8503-cmyk.github.io/country-guesthouse/

## 내용 수정
- `js/config.js`: 전화, 주소, 체크인·아웃, 객실 인원·가격·시설. 주소·입퇴실·객실 인원과 시설은 스마트플레이스 등록 정보를 반영했습니다. 요금·이용 규칙·환불 정책은 `확인 필요`로 표시했습니다.
- `bookingUrl`을 정확한 네이버 예약 URL로 바꾸면 모든 공통 예약 버튼에 반영됩니다. 객실별 `bookingUrl`은 선택 사항입니다.
- 현재 예약 버튼은 네이버 플레이스로 연결됩니다. 플레이스의 예약 메뉴에서 진행합니다.
- `images/photos.json`: 사진 경로·객실·분류·설명·크기. 변경 후 `js/photos.js`의 사진 목록도 함께 갱신합니다.
- 사진은 최대 1440px, JPEG로 최적화했습니다. 객실과 갤러리 사진은 지연 로딩하며 클릭 시 확대됩니다.
- 지도 API 키와 외부 분석·추적 스크립트를 사용하지 않습니다.

## GitHub Pages 공개
저장소 Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save.
배포 완료 후 공개 주소에 접속해 확인합니다. 이후 main에 올린 수정 사항은 자동 반영됩니다.

## 네이버 스마트플레이스 홈페이지 등록
1. 네이버 스마트플레이스에서 시골집손님방 업체를 선택합니다.
2. 업체 정보 관리의 기본 정보 또는 상세 정보에서 홈페이지·웹사이트 항목을 엽니다.
3. `https://wkh8503-cmyk.github.io/country-guesthouse/`를 입력하고 저장합니다.
4. 메뉴 이름은 관리 화면에 따라 다를 수 있습니다. 반영 후 공개 플레이스에서 홈페이지 링크를 확인합니다.

## 사진과 미확인 정보
사진은 기존 작업의 업체 등록 사진 목록을 이어받았습니다. 사진 속 음식·시설이 항상 제공됨을 의미하지 않습니다.
요금·이용 규칙·환불 정책을 확인한 뒤 config.js를 수정하세요. 가상 객실·가상 관광지·예시 가격은 제거했습니다.

## 디자인 구성 (2026-11 개편)
"들판을 바라보는 낮, 불빛 아래 머무는 밤" — 실제 사진으로 낮(들판·냇가)과 밤(마당 불빛·불멍)을 보여 주고, 어느 화면에서든 한 번에 예약으로 이어지게 했습니다.
- 첫 화면 큰 사진 + 체크인/아웃·객실 요약, 낮/밤 두 장 사진, 객실 카드(사진 전체 보기), 바비큐·불멍 이야기, 분류별 사진첩, 이용 안내 + 자주 묻는 질문, 오시는 길(클릭 시 OpenStreetMap 지도), 마지막 예약 안내
- 휴대폰: 메뉴(☰), 화면 아래 고정 `전화 / 네이버 예약하기` 버튼, 사진 넘기기(스와이프)
- 큰 사진에 쓸 사진은 `js/config.js` 의 `heroImage`·`dayImage`·`nightImage`·`fireImages`·`closingImage` 에서 바꿉니다.
- 주차·이용 규칙·환불 규정이 확인되면 `parking`·`rules`·`refundPolicy` 의 `'확인 필요'` 를 실제 내용으로 바꾸세요. 자주 묻는 질문은 `faq` 에서 수정합니다.

## 작은 사진(썸네일)
`images/thumbs/` 에 같은 경로로 가로·세로 최대 640px 사진이 있어 휴대폰에서 빠르게 열립니다. 사진을 추가하면 같은 경로로 작은 사진도 함께 넣어 주세요. (없으면 그 사진은 깨져 보입니다)
